# TOOL-0002: Implement Color Inspector Tool

## Summary

An image of choice is drawn to the screen.
Clicking on any pixel of the image prints an RGB description of the color both to the screen and to the text console.

## Details

See acceptance criteria.

## Acceptance Criteria

- [X] Image can be scrolled using the up, down, left and right arrow keys.
- [X] Double-tapping speeds up image scrolling.
- [X] Image can be zoomed in using the 'z' key and zoomed out using the 'a' key
- [X] Clicking on any pixel of the image prints an RGB description of the color both to the screen and to the text console.
- [X] Image can be chosen from the command-line.
- [X] List of possible images can be viewed with "-i" underscore.
- [X] Stand-in image is loaded when image cannot be found.

## Notes

Color information should be usable as inputs to the Sprite Slicer tool.
