# INFR-0004: Implement Command Line Utility

## Summary

Command Line Tools grant applications the power to leverage command line arguments to be able to affect the behavior of an application.

For instance, for the Color Inspector, the starting image can be chosen via the following command:

	love . inspector --imageFile myImageFile

or

	love . inspector -i myImageFile

## Details

The Command Line Tools are automatically activated for any application with a config/cmdSchema.lua file. This describes what arguments are supported, and what attributes the arguments have.
Attributes include:

1. shortcut: the single-character shortcut that stands in for the argument
2. required: whether or not the argument must be present for the program to run
3. default: what the default value of the argument is if not specified
4. description: an English description for the command signaled by the argument; this description is printed when "help" is requested

Argument values are typically strings, but if a value is not specified, they can be a boolean flag.

## Acceptance Criteria

- [X] Argument values propagate to program
- [X] Support for boolean values
- [X] Support for shortcuts
- [X] Support for required arguments; program automatically fails to run
- [X] Support for default values for arguments, which are automatically substituted
- [X] Support for help via specified descriptions
- [X] Support for multi-line descriptions

## Notes

Currently all cmdSchemas are marked as being VERSION 0.1. This is unlikely to change unless there is a big update forthcoming in the format of commands.
