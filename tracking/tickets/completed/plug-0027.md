# PLUG-0027: Upgrade Color Selector Plugin to allow object with callback

## Summary

The "onColorSelected" parameter should now have the option of
taking an object with the method onColorSelected() instead of
a pure function.

## Details

See acceptance criteria.

## Acceptance Criteria

- [ ] Implement ability to take object with method onColorSelected()

## Notes

The Color Selector Plugin takes the following parameters:
* imageView       - a reference to the imageViewer class
* onColorSelected - a reference to either:
                    1. a callback function which takes r, g, b
                      (each between 0 and 1).
                    2. an object containing the method onColorSelected().
