# TOOL-0005: Implement Scribbler Tool

## Summary

Can make simple, single-color drawings or "scribblings",
with undo/redo functionality and saving and loading from disk.
In addition to scribblings, can draw straight lines and text phrases.

## Details

See acceptance criteria.

## Acceptance Criteria

- [X] Scribble tool implemented
- [X] Line tool implemented
- [X] Text tool implemented
- [X] Undo/redo functionality implemented
- [X] Scribble tool smoothed out, redundancies eliminated
- [X] Can persist scribble data to disk in readable format
- [X] Can read scribble data from disk (command-line functionality)
- [X] Can save snapshot to disk as image
- [X] Can print out catalog of possible scribbles to load

## Notes

Scribbler Tool is currently at 0.1, but is expected to be upgraded to 0.2 with the advent of rectangles, colors, arrows, and selective deleting or moving of jots.
