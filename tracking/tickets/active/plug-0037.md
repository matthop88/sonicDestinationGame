# PLUG-0037: Implement AreYouSure Dialog Plugin

## Summary

The "Are You Sure" Dialog Plugin displays a dialog on the screen
where a customizable message is displayed to the user.
The user can either click on "OK" or "Cancel" buttons.
Each button has an optional callback that can be set up.

## Details

See acceptance criteria.

## Acceptance Criteria

- [ ] "Are You Sure" Dialog Plugin implemented

## Notes

The AreYouSure Dialog Plugin takes the following parameters:
* x          - x coordinate of dialog box (default: 325)
* y          - y coordinate of dialog box (default: 200)
* w          - width  of dialog box       (default: 150)
* h          - height of dialog box       (default: 200)
* okText     - label of OK button         (default: "OK")
* cancelText - label of Cancel button     (default: "Cancel")
* onOK       - callback when OK     is pressed
* onCancel   - callback when Cancel is pressed
