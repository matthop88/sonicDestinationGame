# INFR-0007: Implement Ticket Tracking Engine

## Summary

The Ticket Tracking Engine is able to create a new ticket from a template, automatically populating it with the proper Ticket ID and creation date.

In addition to this, the ticket tracking engine can generate a comment block from an existing ticket that can be pasted into the tool source code itself.

## Details

The tool has two modes:
1. Ticket generation mode. Given a ticket type and title, it generates a ticket with the proper ticket ID and date inside of it. This ticket is added to the clipboard, so it can be pasted into a file.
2. Comment generation mode. Given an existing ticket id, it generates a comment block based upon the contents of the ticket. The comment block is added to the clipboard, so it can be pasted into the source code.

Comment generation mode is designated with the "-c" flag.
